# Quick Task 260514-ix8 — Remove redundant Output section from 5 prompts

## Goal

Delete the `## Output` section from each of the 5 artifact-producing recipe prompts. The output schema for these agents is enforced at the API level via `response_format_model` bindings in `src/robotina/agent/agents.py` (provider-native structured output for Anthropic/OpenAI, `ToolStrategy` wrapper for Ollama), so the prompt-level Output section is redundant. Project convention is that prompts are exclusively for the agent, not for human developers; a sentence pointing developers at `src/robotina/queue/task_types.py` violates that convention.

## Background

- Confirmed in conversation: `langchain.agents.create_agent(response_format=<PydanticClass>)` derives a JSON schema and binds it to the LLM. The model receives the schema independently of the prompt text. See `.planning/decisions/response-format-adoption.md` (Phase 11).
- The Output sections of all 5 prompts contain only type-pointer text (`Return data shaped by X in task_types.py … refer to it; do not re-describe fields here.`) plus, in the case of `recipe-research-gather/V004`, one semantic line ("one entry per usable source") which is already captured in Process step 3, step 4, and the Rules block.
- For `recipe-load/V004`, the field-population guidance ("copy fields from response body verbatim … `recipe_id` ← `id`") lives in **Process step 7** and the **Rules** block, not in the Output section. The Output section's "per the rules above" is a pointer that adds nothing.
