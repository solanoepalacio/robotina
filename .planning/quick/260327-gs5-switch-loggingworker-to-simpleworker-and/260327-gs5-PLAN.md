       "RQ SimpleWorker subclass that emits structured log lines for job lifecycle events.
       Log format: [<queue>] job <id> starting|finished|failed | task_type=<type>

       Remove these two lines:

         _logging.basicConfig(level=_logging.INFO)
       These were only needed in the forked subprocess where the parent's logging config was not inherited. In-process execution inherits the logging config set by configure_logging() in main().

    5. Remove the call to `_setup_langwatch_in_workhorse()` from perform_job(). LangWatch is now set up once in main() before the worker starts.

    6. Simplify _setup_langwatch_in_workhorse() — remove all fork-workaround code. The new function body:
       - Keep the check for api_key and endpoint_url env vars (if not set, warn and return)
       - Remove ALL of the following lines (fork workarounds):
           import opentelemetry.trace
           from langwatch.client import Client
           from opentelemetry.util._once import Once
           Client._reset_instance()
           opentelemetry.trace._TRACER_PROVIDER = None
           opentelemetry.trace._TRACER_PROVIDER_SET_ONCE = Once()
       - Keep only the langwatch import and langwatch.setup() call and the logger.info line
       - Rename the function to _setup_langwatch() (no "in_workhorse" — it now runs in main)
       - Update the docstring: "Initialize LangWatch once at worker startup. Called in main() before worker.work(). No fork-workaround resets needed — SimpleWorker runs in-process."

    7. In main(), call _setup_langwatch() after configure_logging() and before starting the worker. Remove the existing comment that says "Do NOT call langwatch.setup() here." Replace with:
       # SimpleWorker runs in-process — langwatch.setup() is safe here (no fork).
       _setup_langwatch()

    The final perform_job() should look like:

    def perform_job(self, job, queue) -> bool:
        task_type = job.meta.get("task_type", job.func_name)
        logger.info("[%s] job %s starting | task_type=%s", job.origin, job.id, task_type)
        success = super().perform_job(job, queue)
        if success:
            logger.info("[%s] job %s finished | task_type=%s", job.origin, job.id, task_type)
        else:
            logger.error("[%s] job %s failed | task_type=%s", job.origin, job.id, task_type)
        return success
  </action>
