<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM-emitted URL → safe_fetch | Untrusted URL string from user message reaches HTTP client |
| Remote server response → safe_fetch | Untrusted HTTP response (headers, body, redirect Location) flows back |
| DNS → safe_fetch | DNS responses are untrusted (multi-A-record rebinding) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-SSRF-INTERNAL | I/E | safe_fetch (URL host) | mitigate | Reject any URL whose hostname resolves to RFC1918/loopback/link-local/0.0.0.0/multicast IP (any A/AAAA record); IPv4-mapped IPv6 unwrapped before check |
| T-23-DNS-REBIND | T | safe_fetch (DNS resolution) | mitigate | `_resolve_and_check` enumerates ALL `socket.getaddrinfo` records; rejects if ANY is blocked (defeats multi-A-record rebinding) |
| T-23-REDIRECT-INTERNAL | I/E | safe_fetch (redirect handling) | mitigate | `follow_redirects=False`; manual redirect loop re-validates scheme + DNS + IP on every Location; max 3 hops |
| T-23-REDIRECT-LOOP | D | safe_fetch | mitigate | Hard cap of 3 hops, raises SafeFetchError on exceed |
| T-23-OVERSIZE-FETCH | D | safe_fetch (body size) | mitigate | Content-Length header pre-check ≤ 2× max_bytes; post-decode body cap ≤ max_bytes (default 5 MB) |
| T-23-GZIP-BOMB | D | safe_fetch (decompression) | mitigate | Reject when decompressed/compressed ratio > 20:1; also reject decompressed > max_bytes |
| T-23-PROTO-SMUGGLING | S/E | safe_fetch (scheme) | mitigate | Scheme allowlist: `https://` only; `http://` requires `URL_INGESTION_ALLOW_HTTP=true` env (default off) |
| T-23-CONTENT-TYPE-MISMATCH | T | safe_fetch (response sniff) | mitigate | Reject when Content-Type not in expected set (text/html, application/xhtml+xml for HTML; image/* for images) |
| T-23-SLOW-LORIS | D | safe_fetch (timeouts) | mitigate | `httpx.Timeout(connect=5, read=timeout_s, write=5, pool=5)` — every phase bounded |
| T-23-URL-LEAK-LOG | I | safe_fetch (logging) | mitigate | INFO logs strip query string via `httpx.URL(url).copy_with(query=None)`; full URL only at DEBUG |
</threat_model>
