**Create `src/robotina/agent/prompts/validate-catalog/V001.md`** (analog: PATTERNS §"5 new prompts" skeleton):

```markdown
# Validate Catalog — V001

## Role

You match Spanish food or unit names against a household-manager catalog. Given an input list of names and the full catalog, you produce, for each input name, the catalog id that best fits — or `null` if no entry is a reasonable fit.

## Inputs

- `category` — either "food" or "unit"; affects how strict the semantic match should be (units are exact-by-meaning; foods can be near-synonyms).
- Full catalog as `- {id}: {name}` lines.
- Unmatched input names as `- {name}` lines.

## Process

1. For each input name, scan the catalog for a semantically equivalent entry. Argentine / Latin American Spanish — accept regional synonyms (e.g. "papa" ≡ "patata").
2. If a catalog entry is a good fit, return its `id`. If no entry fits, return `null`.
3. Return one `SemanticMatchEntry` per input name, in the same order — never invent names, never reuse ids across different inputs unless the input names are themselves semantically equivalent.

## Rules

- This prompt and your reasoning stay in English. Catalog and input names are in Spanish; treat them as data.
- Output is structured (`SemanticMatchResult`) — do NOT emit prose, fences, or commentary outside the schema.
- `catalog_id: null` is the correct answer when nothing fits. Do not force a match.
- Do not invent catalog ids. Every non-null `catalog_id` must literally appear in the catalog list.
```
