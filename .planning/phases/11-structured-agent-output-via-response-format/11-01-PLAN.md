Purpose: This plan is the contract surface — every later plan in Phase 11 imports the kwarg shape, the `response_format_model` field, and the requirement IDs from here. The Strategy-wrap is a correctness requirement (not aesthetic): Ollama's `gpt-oss:20b` matches `FALLBACK_MODELS_WITH_STRUCTURED_OUTPUT` (`langchain/agents/factory.py:148–158`) so passing a bare class to AutoStrategy would silently route to ProviderStrategy and call `bind_tools(strict=True, response_format=...)` on ChatOllama — which Ollama does not honor. The explicit ToolStrategy wrap in OllamaBackend is the only safe path.
