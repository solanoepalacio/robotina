<objective>
Close UAT gap: rename start_workflow → queue_workflow, create WorkflowRun as PENDING, and transition to RUNNING in on_step_start when the worker picks up the first step.

Purpose: The current implementation sets WorkflowRun.status=RUNNING at creation time, which is semantically wrong — the workflow is enqueued but not yet executing. PENDING correctly represents the queued-but-not-started state; RUNNING should only be set when a worker actually begins executing the first step.
