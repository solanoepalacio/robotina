<objective>
Move the workflow acknowledgment ("Voy a buscar esa receta…") out of the routing agent (`handle-incoming-message`) and into a dedicated `acknowledge-add-recipe` agent that runs as workflow step 1. After this plan, the routing agent emits exactly ONE tool call on each path (`queue` for direct replies, `start-workflow` for workflows). Plan 03 then makes both tools terminal — but Plan 03 is wrong without Plan 02 first because terminal `queue` would break today's "queue then start-workflow" sequence.
</objective>

<context>
@.planning/phases/07.1-deterministic-agent-termination-make-termination-a-runtime-g/07.1-CONTEXT.md

The routing agent today does two things on Path B (workflow request): (a) compose a Spanish acknowledgment and call `queue` with it, then (b) call `start-workflow`. We're moving (a) out into a per-workflow agent. The `add-recipe` workflow gains a new first step `acknowledge` that runs the new agent.

Per `feedback_avoid_premature_abstraction.md`, this agent is per-workflow (not generic). When/if we add a second workflow type that wants an ack, we'll add `acknowledge-<workflow>` for it. Refactor to a generic agent only after ≥3 instances exist.

Per `feedback_prompts_language.md`: prompt in English, output in Spanish.

The new ack agent uses the existing `QueueTool` (still non-terminal at this point — Plan 03 makes it terminal). Per `feedback_queue_at_front.md`, `QueueTool` already enqueues with `at_front=True`, so the ack delivery jumps any pending workflow steps.
</context>

<task name="1: Add AcknowledgeAddRecipeInput task type">
**File:** `src/robotina/queue/task_types.py`

Add a new Pydantic v2 input model. Keep it minimal — only what the agent needs:

```python
class AcknowledgeAddRecipeInput(BaseModel):
    recipe_query: str
    reply_context: dict  # {platform, chat_id, user_id} — auto-injected by StartWorkflowTool

    @property
    def chat_id(self) -> str:
        return self.reply_context["chat_id"]

    @property
    def user_id(self) -> str:
        return self.reply_context["user_id"]

    @property
    def platform(self) -> str:
        return self.reply_context["platform"]

    def to_user_message(self) -> str:
        return (
            f"User is requesting to add a recipe: \"{self.recipe_query}\". "
            "Compose a brief, friendly acknowledgment in Spanish that you will "
            "search for the recipe and that data will be updated directly in the application."
        )
```

`reply_context` is the same dict that `StartWorkflowTool` already auto-injects into `shared_context` (see `start_workflow.py:74-78`). The `chat_id`/`user_id`/`platform` accessors mirror the shape that `jobs.py` expects when injecting `QueueTool`.

<task name="2: Create the acknowledge-add-recipe prompt">
**File:** `src/robotina/agent/prompts/acknowledge-add-recipe/V001.md` (new)

```markdown
> **IMPORTANT: You MUST respond in Spanish. Your output is delivered to a family member via Telegram.**

# Acknowledge Add-Recipe — V001

You are an acknowledgment agent for Robotina. The user just requested that we add a recipe to their household cookbook. Your only job is to send a brief, friendly Spanish acknowledgment confirming that we are working on it.

## Instructions

1. Compose a short Spanish acknowledgment (1-2 sentences) referencing the recipe they asked for.
2. Tell them the data will be updated directly in the application.
3. Call the `queue` tool with that text. When `queue` returns, the task is done — stop.

## Style

- Warm, casual Spanish appropriate for a family household assistant.
- Keep it brief — this is just an acknowledgment, the actual work happens in subsequent workflow steps.
- Do NOT promise a specific outcome or timeframe.
- Do NOT ask follow-up questions.

## Example

User: "Voy a agregar la receta de bocaditos de arroz"
Acknowledgment: "Voy a buscar la receta de bocaditos de arroz y la guardo en tu recetario. Los datos se actualizarán directamente en la aplicación."

## Critical Rules

- Call `queue` exactly once and stop.
- Do not call any other tools.
- Plain text — no Markdown formatting.
```
