## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Agent / user input → `step_input` JSON column | The dict returned by `build_input(...)` may contain user-supplied content (Telegram message text, household IDs, recipe URLs). This plan persists it; the dashboard plan (13-02) renders it. Storage is the trust-boundary crossing here. |
| Exception object → `failure_reason` Text column | `exc` may be any `Exception` subclass; its `__str__` may contain user-influence-derived content (e.g., a `ValidationError` echoing a malformed URL). The fixed format + newline normalization is the mitigation. |
| Internal queue dispatcher | `jobs.py` catches `Exception` (not `BaseException`) so `KeyboardInterrupt` / `SystemExit` are not persisted as workflow failures. |
