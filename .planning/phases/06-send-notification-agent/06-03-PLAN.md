**escaping.md content** — Complete MarkdownV2 escape reference:

```
# MarkdownV2 Character Escaping

All 18 special characters MUST be escaped with a backslash when they appear as
literal text (not as formatting markers). Failure to escape causes Telegram to
return: Bad Request: Can't parse entities

## Characters Requiring Escape

| Character | Escaped Form | Common Context |
|-----------|--------------|----------------|
| _ | \_ | Underscores in words |
| * | \* | Asterisks in text |
| [ | \[ | Square bracket open |
| ] | \] | Square bracket close |
| ( | \( | Parenthesis open |
| ) | \) | Parenthesis close |
| ~ | \~ | Tilde (approximate sign) |
| ` | \` | Backtick |
| > | \> | Greater-than |
| # | \# | Hash / number sign |
| + | \+ | Plus sign |
| - | \- | Hyphen / dash |
| = | \= | Equals sign |
| | | \| | Pipe / vertical bar |
| { | \{ | Curly brace open |
| } | \} | Curly brace close |
| . | \. | Period / full stop |
| ! | \! | Exclamation mark |

## Rules

1. Escape ALL occurrences, not just the first.
2. Do NOT double-escape. If the character is already escaped (\.), leave it.
3. Inside code spans (backtick-delimited), only backtick and backslash need escaping.
4. Inside pre blocks (triple-backtick), only backtick and backslash need escaping.

## Quick Examples

| Input text | Correct MarkdownV2 |
|------------|-------------------|
| Ready in 30 min! | Ready in 30 min\! |
| (serves 4) | \(serves 4\) |
| cost: ~8.50 | cost: \~8\.50 |
| prep: 10 min. | prep: 10 min\. |
| Mon-Fri | Mon\-Fri |
| step 1 + step 2 | step 1 \+ step 2 |
```

**formatting.md content** — MarkdownV2 structural formatting:

```
# MarkdownV2 Formatting Syntax

## Bold

Wrap with *text*:
- Input: Recipe saved
- Output: *Recipe saved*

## Italic

Wrap with _text_ (underscores — remember to escape underscores in non-italic text):
- Input: Note
- Output: _Note_

## Inline Code

Wrap with backticks:
- Input: carbonara
- Output: `carbonara`

## Hyperlink

[display text](url) — escape all special chars in display text:
- Input: link to recipe
- Output: [View recipe](https://example\.com/recipe)

## Bullet Lists

Use hyphen as bullet marker. Escape the hyphen marker itself:
- Each bullet line: \- Item text here
- Example:
  \- Monday: pasta
  \- Tuesday: soup
  \- Wednesday: salad

## Numbered Lists

MarkdownV2 has no native numbered list syntax. Use plain numbers with escaped period:
1\. First step
2\. Second step
3\. Third step

## Line Breaks

Use a single newline between lines in the formatted string.
```

```
Real examples of notification messages before and after MarkdownV2 formatting.

#### Example 1: Simple confirmation

Before:
  The recipe has been saved successfully.

After:

#### Example 2: Structured data

Before:

Before:

After:
  *This week's meal plan:*

  \- Friday: pizza

#### Example 4: Special characters

Before:
  Ready in 30 min! (serves 4) — cost: ~€8.50

After:
  Ready in 30 min\! \(serves 4\) — cost: \~€8\.50

Key escapes: ! becomes \!, ( becomes \(, ) becomes \), ~ becomes \~, . becomes \.

| Mistake | Wrong | Correct |
|---------|-------|---------|
| Unescaped period | 10 min. | 10 min\. |
| Unescaped exclamation | Done! | Done\! |
| Unescaped tilde | ~3 hours | \~3 hours |
| Unescaped hyphen (as literal) | Mon-Fri | Mon\-Fri |
| Unescaped parentheses | (optional) | \(optional\) |
```

```
# Notification Agent — V001

You are the Notification Agent for Robotina, a household management assistant.

## Your Role

Your ONLY job is to reformat a pre-written message for delivery via Telegram and
then send it. You do NOT compose content, summarise, or add any information.

The message you receive has already been written by another agent. Your job is to
make it render correctly in Telegram using MarkdownV2 formatting.

## Instructions

1. Read the format-telegram-message skill to understand Telegram MarkdownV2 rules.
   Start with escaping.md — escaping errors are the most common problem.

2. Apply MarkdownV2 formatting to the message text:
   - Escape all 18 special characters that appear as literal text
   - Use bold (*text*) for labels and headings
   - Use bullet lists for multi-item content
   - Do NOT add content that was not in the original message

3. Call the send-notification tool with the formatted text.

## Critical Rules

- REFORMAT only. Do not add, remove, or change the meaning of any content.
- The input text is already correct — your only job is presentation.
- Every special character (., !, (, ), -, ~, etc.) that appears as literal text
  MUST be backslash-escaped. Missing an escape will cause a Telegram API error.
- Call send-notification exactly once with the final formatted text.
- Do not ask clarifying questions. Format and send.

## Failure Modes to Avoid

Wrong: Adding context or expanding the message (e.g., "Here is your recipe: ...")
Wrong: Summarising the message instead of reformatting it
Wrong: Sending the raw unformatted text without applying MarkdownV2 escaping
Right: Reformat the exact content, escape all special chars, call send-notification
```
