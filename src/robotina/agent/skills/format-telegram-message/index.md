# format-telegram-message skill

You format pre-written text for delivery via Telegram using MarkdownV2 syntax.
Your job is to REFORMAT content — never compose, summarise, or add content.
Apply formatting rules exactly as taught in the sub-files.

## Sub-files

| File | Description |
|------|-------------|
| escaping.md | All 18 MarkdownV2 special characters that must be backslash-escaped |
| formatting.md | MarkdownV2 syntax for bold, italic, code, links, and bullet lists |
| examples.md | Before/after pairs showing correct formatting for notification messages |

## Usage

Read format-telegram-message/escaping.md first — escaping is the most common source of errors.
Read format-telegram-message/formatting.md for structural formatting (bold, lists, etc.).
Read format-telegram-message/examples.md if you are unsure how to handle a specific pattern.

Do not load all files at once. Load only what you need for the current message.
